# Competitor SEO Market Signals

**Category:** seo_aeo
**Purpose:** Dated search/visibility evidence for competitor-aware SEO planning.
**Does not own:** Competitor positioning, battlecards, product comparisons, sales claims, or public comparative language.

## Source Boundary

Use this file only to record that competitor-aware search opportunities exist. Named competitor selection, positioning, and comparative public claims must be validated through the current workflow, including vault retrieval and approved source mapping where Simpro language or proof is involved.

## Allowed Use

- Seed keyword and SERP research.
- Identify pages that may need competitor-aware intent coverage.
- Track dated measurement artifacts and gaps.
- Inform which public sources need fresh verification.

## Not Allowed

- Do not copy positioning, battlecard language, sales notes, or product claims from this file.
- Do not use this file to decide a public competitor shortlist.
- Do not use this file to describe Simpro or a competitor in public copy.
- Do not infer feature, pricing, implementation, review, or customer claims from historical notes.

## Refresh Rule

Any competitor-aware article or page must run the current competitor workflow and record a `Competitive Shortlist Decision` in the validation sidecar. This reference is only a dated SEO-research pointer.
